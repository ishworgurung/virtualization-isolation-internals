Replay the ABA interleaving against an untagged and a tagged Treiber stack.

There is only ONE real thread here. “T1” is the pop_with_hook call that reads head, then pauses; “T2” is the closure it runs in that pause. This reproduces, deterministically, an interleaving that with real threads would happen only rarely (T1 would have to be descheduled at exactly that point).

Nodes are numbered 0, 1, 2 and shown as A, B, C. The step-by-step picture of what happens is in the module docs of src/aba.rs.

Run: cargo run –release –bin aba_demo
