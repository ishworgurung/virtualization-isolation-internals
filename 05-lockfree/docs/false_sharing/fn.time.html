pub(crate) fn time<F: FnOnce()>(f: F) -> f64
Expand description

Run f and return how long it took, in milliseconds.

<F: FnOnce()> makes this a GENERIC function: F stands for “whatever type the caller passes”, with the constraint that it must be callable once with no arguments (every closure has its own unique type, so we can’t name it; generics let us accept any of them). -> f64 is the return type. Instant::now() reads a monotonic clock; elapsed() is the time since then; * 1e3 converts seconds to milliseconds. The last expression without a ; is the function’s return value (no return keyword needed).
