pub fn pop_with_hook(&self, between: impl FnOnce()) -> Pop

One pop attempt. between runs after we read head and head.next but before the CAS — the window in which ABA happens. In production code there is no such hook; the “hook” is another CPU.

(impl FnOnce() means “any closure taking no arguments that we call at most once”. The demos pass a closure that plays “thread 2”.)

pub fn scribble_next(&self, idx: u32, next: u32)

Overwrite a node’s next — simulates its new owner reusing the node after popping it (e.g. as part of some other list).

Source

pub fn snapshot(&self) -> Vec<u32>

Walk the stack top-down (bounded, so a corrupt list cannot loop us forever). A corrupted list can contain a cycle (A -> B -> A -> …); a list of n nodes can never legitimately be longer than n, so we stop there.
