pub fn is_v2() -> bool
Expand description

Is this a cgroup v2 (unified hierarchy) host? v2 has a single tree with a cgroup.controllers file at its root; v1 mounts one tree per controller (/sys/fs/cgroup/cpu, /sys/fs/cgroup/memory, …). (A “hybrid” host mounts v1 trees there and v2 at /sys/fs/cgroup/unified; this function reports false for it.)
